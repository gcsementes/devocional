# GC Sementes — Devocionais

Site estático de devocionais diários do GC Sementes.

## Publicação no GitHub Pages

1. Crie um repositório e envie os arquivos desta pasta (exceto `.referencia-original`, que é apenas uma cópia local de consulta).
2. Em **Settings → Pages**, escolha **Deploy from a branch**.
3. Selecione a branch `main` e a pasta `/(root)`.

O site estará disponível em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

Os devocionais ficam em `devocionais.js`; o conteúdo exibido é escolhido automaticamente pelo dia.
